## 0. 一句话结论

把线性侧刚兑现 +207 的「每通道能量均衡」类迁移到注意力侧：对 q 的 (kv-head, dim) 通道乘 s、
对 k 除以 s（logits 精确不变），s 取闭式 **s_c ∝ (B_c/A_c)^{1/4}**（A=q 通道能量、B=k 通道能量，
k 就是 q 的"权重列"，反之亦然），挂在 per-head 旋转**之前**的原空间，配「结构稳定性滤波 +
部署感知守门」双保险。mini 真实 test **+1.83pp/case（5/5 全正）**，合成结构组 **平均 +8.0pp、
负频率 5%**，true-iid 组 8/8 正确拒绝（位级回退），官方 self_check 22/22。

## 1. 机制与闭式推导

### 1.1 不变量与误差足迹
Q/K 联合平滑：q_h 通道乘 s、k_{h//rep} 通道除 s ⇒ (q⊙s)·(k/s) = q·k，logits 精确不变
（s 必须在 GQA 组内共享，否则 k 无单一定标可配）。量化后：
δL ≈ Σ_c e_{q,c}·k_c/s_c + q_c·s_c·e_{k,c}。

部署误差模型（与部署管线一致）：per-head Hadamard 旋转把 head 内能量摊平——对固定符号
模式，旋转后通道 j 的总体方差 = (1/dh)Σ_c A_c，**逐通道精确相等**；HiF4 每 64 块 absmax
定逐元素误差尺度 ⇒ 误差在 head 内均匀。于是每 head：
E[δL²] ∝ (Σ_c A_c s_c²)·(Σ_c B_c/s_c²)（A=q、B=k 通道能量，原空间）。

**Cauchy–Schwarz**：(Σ a)(Σ b) ≥ (Σ√(ab))²，取等 iff a∝b，即 A_c s_c² ∝ B_c/s_c²
⇔ **s_c ∝ (B_c/A_c)^{1/4}**（与 linear 侧 ff_bal 同一闭式；head 内整体缩放 λ_h 是自由参数，
按 head 几何均值 1 归一）。收益存在当且仅当 per-channel B/A 比值异质且跨样本持久。

### 1.2 先均衡后旋转 vs 旋转空间内均衡（两种都测了）
- **理论**：旋转后通道能量总体精确平坦 ⇒ 旋转空间内拟合没有真实信号；原空间拟合的
  q/k 能量 trade-off 经旋转完整保留（只通过两个和进入误差）。
- **实测**（旋转空间 pooled-calib vs test 的 log(B/A) 相关 = post-arm 能吃的全部信号）：
  gqa32x8x64 0.39/0.52、**gqa16x2x256 0.07/0.06**、mha8x8x128 0.32/0.52 —— 对比原空间 0.995。
  **取 pre，post 理论+实测双杀，不设 post 臂。**

### 1.3 与旧死路（v11 "Q/K 通道 smoothing"、dev/qksm.py）的区别
旧死路 = 旋转后空间 + 参数化单 β 全局指数 + |mean| 统计量（旋转已把均值摊平 ⇒ 无信号，
mini +2%/合成 ~0）。本次 = 原空间 + 每通道自由闭式 + 能量统计 + 双守门。同类先例：
linear 侧把参数化 α 搜索（恒选 s=1 的死代码）换成闭式后 0→+5.5pp、线上 +207。

## 5. 守门设计与安全性

双层守门（全程不碰全局 RNG；任何拒绝/异常路径与基线**位级相同**，torch.equal 实测：
off==baseline、拒绝==baseline、iid 拒绝后分数逐位 0.00）：
1. **结构稳定性滤波**（必要，新增）：calib[:-1] 内 per-sample log(B/A) 图两两相关中位数
   ≥ 0.5 才放行。true-iid 下该统计 ~N(0,1/√(kvh·dh))≈0（实测 −0.00~0.01 → 拒），
   结构数据 ~0.97。这是对"假设类是否成立"的直接检验，封住纯结果守门的偶然接受尾
   （修复前 iid 8 种子 1 例泄漏接受、−8.6pp）。
2. **部署感知结果守门**：末样本 strided ≤256 行，4 条链（s∈{1,s}×rot∈{0,1}）线程重叠，
   快速表量化器（linear 侧已验证的代理，比全搜索快 4-8×）量化双侧 + 真实 attention
   输出 MSE，接受 iff j_cand < 0.998·j_base（两臂各自对 mode 取 min，苹果对苹果）。

安全测试结果：iid 8/8 拒；离群 token 8/8 拒（保守方向正确，与 linear ff_bal 行为一致）；
非 2 幂 dh（R=None）自动退化为单 mode 守门；qh%kvh≠0 或 calib<3 跳过机制。
**cs_tf 对抗 regime（calib 有结构、test 无结构）：守门构造性失明（fit+hold 全在 calib 侧），
实测 −12~−26pp，不可守门**。接受理由：(1) mini test/calib ratio corr 0.998 强反驳；
(2) v34 探针 +10 = 判题注意力结构真实（否则 calib Hessian 精化应负不应正）；(3) linear 侧
同类盲区上线兑现 +207。回滚开关 QKS_MODE="off"（位级）。分桶若指向 attention 即第一嫌疑。

## 8. 次要任务结果

### 8.1 ff_bal 接受率普查（stress_data 16 配置，census.py / census.json）
**0/16 接受，全部正确**：所有 stress 配置是逐样本独立 gains（true-iid 结构），闭式 s 无物可吃，
j_cand 反而比 j_base 差 5-30%（拟合噪声有害）→ 守门拒绝既正确又必要（位级回退）。
结论：**"+207 只有 mini 预测 21% 接受"不是守门误杀，是判题线性组真实结构远强于一切
stock-synth 数据**——守门在无结构数据上零误伤（0 假阳性价值损失），在有结构数据上全收。
c2048_tiny（单 calib 样本）机制自动跳过（无 holdout 可守）。
### 8.2 ff_icm 守门泄漏修复 —— 建议不修（无免费增强可拿）
smooth 电池里 ff_icm 在全部结构配置上 ≈ ff_bal（差 ≤0.05pp），汇总反而更差
（+5.15 vs +5.46，被 outl 泄漏拖累）。即使把 outl 守门修到 0 泄漏，ff_icm 也只是追平
ff_bal——修复的期望收益 ≈ 0，而守门改动有引入新泄漏的风险。**弃修，记台账。**
