# msel：多 s 变体逐调用选择（multi-s per-call selection）— 机制探索报告

**日期**: 2026-08-24  **判定: NO-SHIP（第一步"值不值得"即判死，未建机器）**
— 65 调用 × 3 变体臂，**真实赢面 0/65**；且存在结构级定理杀死整个类，与实现质量无关。

## 0. 一句话结论

平滑不变性 (x·s)@(w/s)^T = x@w^T 要求**两侧同一 s**；判题器把权重侧冻结在校准返回的
单一 weight_params 上（每个测试用同一 w_play 评分），因此动态侧换任何 s_v 都要吃
一阶失配罚分 ‖x·diag(s_v/s_ship−1)·w^T‖² —— 实测该罚分（连**零量化误差**的变体完美输出都算上）
在 194/195 变体-调用对上**超过 ship 默认的全部量化误差**。逐调用择优没有可买的东西，
假设的价值源（小 T 调用偏好小-T 拟合的 s）实测不存在（J 差距对 T 平坦）。

## 1. 结构级定理（为什么这类机制必然死）

1. 判题算分（dev/hif4.py 语义）：每测试 `mse = ‖x_play @ w_play^T − x_ref @ w_ref^T‖²`，
   其中 `w_play = dequant(weight_params)` 是校准的**单一返回值**，所有测试共用。
2. 精确目标（r1024v 修过系数版，本报告复用并验证）：
   `J(v) = ⟨v, v@gw⟩ − 2⟨v, x_ship@gwf⟩ = ‖v@q^T − x@w^T‖² + const`，
   交叉项必须用 **x_ship**（ship 的 s 变换后输入）。
3. 动态侧走变体 s_v 产生的 v ≈ rot(x·s_v)，判题按 rot(w/s_ship) 评分：
   输出 ≈ x·diag(s_v/s_ship)·w^T，失配罚分 ≈ E[(r−1)²]·‖x@w‖²（r = s_v/s_ship）。
4. **两段式死亡**：任何两个独立拟合的 s 至少相差 ~0.05 rms log-ratio（拟合噪声地板，
   见 §3 resamp 臂实测），0.05 的失配即罚 ~0.25% 信号功率 —— 而 ship 默认的**全部**
   量化误差只有 ~0.1–0.2% 信号功率（pp 85–95）。要赢需要 rms log-ratio < ~0.01，
   这种"变体"与 s_ship 统计上不可区分（拟合噪声 0.06），无物可选。

## 2. 实验设置（第一步协议：先测值不值得）

- 基线副本 `dev/msel/solution.py`（= 主线 solution.py，SMOOTH_MODE=ff_bal，未改动）。
- 数据：**mini linear.pt**（真实判题数据，N=8192/C=2048，calib T=[10,128,512,1024,1024]）
  + **12 个合成组**（6 配置 × 2 种子）：c1024/c2048/c4096_shared、c2048_sp09（强结构）、
  c2048_partial（share=0.7，测试分布≠校准——假设的价值源场景）、c2048_wsp09（权重尖峰）。
  生成器沿用 dev/smooth/exp_smooth.py 的共享通道结构族，T 组成对齐判题
  （calib 10/128/512/1024，test 10/128/512/1024/2048，含 R>tmax 人群）。
- 全部 13 组：ff_bal 守门**接受**、mode=1、g=1、grams 携带 —— 即机制处于**满机会regime**
  （变体路径享有与 ship 相同的 GPTQ+精化机器）。
- 变体臂（校准期同一数据拟合，仅 C 维向量不同）：
  - `smallT`：_bal_search 只用 calib[:-1] 的 T≤128 样本（10+128 行，90 行）；
  - `mag`：mag_scan 参数化 τ 族（部署感知代理选 τ）；
  - `resamp`（补测）：_bal_search 用**另一随机子样本**的全量行（测拟合噪声地板）。
- 变体动态路径（提案的字面轻量形态）：`x*s_v → rot → 表量化 →（g=1 时）shipped u_act/order GPTQ →
  （R≤tmax 时）携带 grams 精化`，即 ship 机器原样、只换 s 向量。
- 每调用记录：`j_true`（交叉项 x_ship，= 判题 MSE + const，已对照直接 MSE 验证，
  ΔJ/Δ(MSE·T·M) = 1.0001）；`j_perf`（变体**完美输出 x_v 本身**，零量化误差——任何变体
  路径量化器的输出都不可能好过它的上界论证）；`j_lit`（提案字面规则，交叉项 x_v）；
  直接判题 MSE。

## 3. 核心证据：J 差距分布（65 调用 = mini 5 + 合成 60）

### 3.1 判定门槛

| 量 | 结果 | 门槛 |
|---|---|---|
| 最优变体 = 默认（J 差 < 1e-4 相对信号） | **65/65 = 100%**（见 §3.3 噪声勘误） | >70% 即 NO-SHIP |
| 变体真实赢面（直接 MSE，无 gram） | **0/65** | — |
| 完美输出地板输给默认（j_perf > j_def） | smallT 64/65，mag 65/65，resamp 65/65 | — |

### 3.2 相对 J_true / 直接 MSE 分布（相对默认）

| 臂 | rms log-ratio(s_v/s_ship) | 中位 rel J_true（信号） | 中位 rel_mse（判题 MSE） | 最好 rel_mse |
|---|---|---|---|---|
| smallT | 0.043–0.185 | +4.27e-3 | **+200%** | +43% |
| mag | 0.199–0.621 | +3.97e-2 | **+2135%** | +599% |
| resamp | 0.056–0.147 | +4.33e-3 | +170%（mini T=10 达 +181% J） | +30% |

mini（真实判题数据）逐调用 rel_mse：smallT +341%…+1834%，mag +24600%…+52200%。

### 3.3 唯一"翻转"的勘误（mini T=128，smallT：rel J_true = −1.24e-4）

携带 bf16 grams 的 J 有 ~1e-3 相对噪声：该调用 dJ(bf16 grams) = −1425，而
dJ(精确 fp32 grams) = **+8944 = 直接 MSE×T×M（+8943.4）**，即 bf16 gram 舍入在 1e-4
相对水平翻转了符号。真实结论：**0/65 赢**。（附带发现：携带 grams 的逐调用选择分辨率
受 gram 存储精度限制在 ~1e-3 相对，任何未来选择类机制需注意。）

### 3.4 价值源检验：T 依赖不存在

per-T 中位 rel J_true（smallT）：T=10 +4.06e-3 / T=128 +4.19e-3 / T=512 +4.27e-3 /
T=1024 +4.31e-3 / T=2048 +4.46e-3 —— **平坦甚至随 T 递增**。失配罚分是 s 向量对的
属性，与调用的 T 无关；"小 T 调用偏好小-T 拟合的 s" 被证伪（mini T=10 的 resamp 臂
反而是最大损失 +1.81）。

### 3.5 提案字面规则是负资产

字面 J（交叉项 x_v，即提案原文"J = ⟨v,v@gw⟩−2⟨v,x@gwf⟩"里的 x 若按变体输入理解）
在 **90.8% 调用上发散**（选中变体），且每次发散**都伤害真实目标**：选中变体的真实
rel J 中位 +4.46e-3（≈判题 MSE ×2–3）。原因：字面 J 把 v 与错误参照
x_v@w/s_ship 比较，系统性偏好"把自己错误目标量化得最好"的变体。正确规则必须用
x_ship 交叉项 —— 而正确规则下没有任何变体赢。

### 3.6 机制验证（证据自身的可靠性）

- J 公式对照直接 MSE 差分：比率 1.0001（bf16 gram 噪声级），与 r1024v 结论一致。
- 13/13 组守门接受 ff_bal（s_ship 是真实拟合值，非回退 1）→ 变体比较在"有结构、
  有平滑收益"的 regime 下进行，非稻草人。
- 变体路径享有全套机器（GPTQ+精化）；j_perf 上界论证封死"实现不够好"的质疑。
- 失配罚分理论值 E[(e^lr−1)²] 与实测 j_perf 地板同数量级（多数组 2–3× 内；
  mini/smallT 例外：(r−1) 集中在低能量通道，罚分被缓和 50×——但实测仍全输）。

## 4. 结论与建议

- **NO-SHIP**。按协议第一步判死，未实现 state 携带/逐调用择优机器，未动计时预算。
  （若实现，动态路径 ×k 是 >+100% 在线时间，远超 +30% 红线——已无意义。）
- **建议记入 STRATEGY.md §7 死路清单（定理级）**：判题器权重侧冻结于单一
  weight_params ⇒ 平滑/缩放类变换的动态侧多变体逐调用选择结构性死亡：失配罚分
  （~信号×E[(s_v/s_ship−1)²]）对任何独立拟合的变体（rms log-ratio ≥ ~0.05 拟合噪声
  地板）都大于全部量化误差预算。与 r1024v-B"固定 s 下逐调用 argmin 空转"合并理解：
  **固定 s 候选定死（0/35），换 s 候选必输（0/65）——动态侧逐调用选择类全谱系关闭**。
- 对主会话的正向残留：携带 grams 的精确 J 打分器（交叉项 x_ship 版）仍可作为
  "未来引入可能变差的新动态变体时的安全网"复用（r1024v 已有实现）；bf16 gram 的
  ~1e-3 相对噪声地板是任何 gram 打分选择的分辨率下限。
