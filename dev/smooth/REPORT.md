# T3c 自由形式平滑 scale（free-form smoothing）— 探索报告

**日期**: 2026-08-24  **判定: SHIP（ff_bal 变体）** — 双 holdout 全门槛大幅通过。

## 0. 一句话结论

把线性侧动态量化的每通道平滑 s 从「参数化 alpha 搜索（实测基本恒选 s=1，等于死代码）」换成
**闭式每通道最优 s_c ~ (GwW_c/GxA_c)^(1/4) + 部署感知守门**，在判题代表性的持久通道结构数据上
**B 样本平均 +5.5pp/case（64 次运行 0 负）**，mini 单 holdout **+5.4~+6.9pp**、真实 test **+3.9pp**，
校准增量 +0.02~0.4s/组，state 字节数不变。是扫描轴之后最大的单一机制。

## 1. 机制与为什么现在才找到

### 1.1 现状（读码确认）
- s 现有来源：`hif4_calibration_and_quantize_weight` 里 `s = exp(logm·α)`，
  α ∈ {0, 0.15, 0.3, 0.5}，代理 = `((a_big @ wq.T − a_big @ w_rows.T)^2).mean()`
  —— **只有权重侧量化误差，激活侧完全没进目标**。
- 实测（mini + 合成）：代理恒选 **α=0（s≡1）**；且 α>0 的参数方向（放大大激活通道）
  与正确方向（缩小大激活通道）**相反**。即当前平滑是死代码。
- W 列补偿挂点：`w_s = w / s; acts_s = [a*s]`，下游（旋转/GPTQ/refine/Gram 携带）全部在
  平滑空间自洽，s 任意取值管线一致 —— 挂点无风险。

### 1.2 为什么自由形式有收益（理论 + oracle 实测）
- mini（判题真实数据）：通道结构**强持久**（log 均值范围 ±4.5，test-vs-calib 通道均值
  相关 0.64~0.94），而权重列几乎平坦（log std 0.078）。
- 部署管线选 mode=1（块对角 Hadamard 旋转）。旋转把 64 块内的大通道能量摊到全块，
  **小通道信息被大通道能量淹没**（每元素误差 ∝ 块能量）。预均衡 s_c·x_c 后再旋转，
  块内能量均匀 → 每元素误差均匀最小。
- 在旋转（部署）视图下最小化 `(Σ_c A_c s_c²)(Σ_c B_c/s_c²)`（A=激活通道能量，B=权重列能量）
  得闭式解 **s_c ∝ (B_c/A_c)^(1/4)**；平坦权重时 = 激活增益^-0.5。
- oracle 对照（合成共享结构，真实增益做 s）：τ=0.5 全管线 **+4.2pp/case**，曲线单峰；
  闭式 ff_bal 达 **+6.0~+6.2pp**（额外吃到权重列结构，w_spread=0.9 组 +12.5pp）。
- **关键教训（记台账）**：朴素表量化代理（无旋转，双边量化）与真实结局**反相关**
  （它判 s=1 最好，实际 τ=0.5 最好）——旋转把 W/s 侧被 s 放大的列散布洗掉了。
  任何平滑类评估必须建模部署旋转。守门代理因此设计为「旋转感知 + 激活侧量化 +
  权重侧不量化（77/23 误差预算）+ 双 mode 取小」。

## 2. 双 holdout 协议与结果（合成）

协议：每 (配置, 种子) 造独立 (A,B) 样本对；A = calib[:-1] 拟合 + calib[-1] 守门
（与管线既有 holdout 纪律一致），B = 独立 test 样本（共享通道结构、新 token）。
8 种子 × 9 配置 × 5 臂。评分 = (mse_std−mse_play)/mse_std vs 精确 alg1，pp/case。

## 4. 成本

- 校准增量（ff_bal）：合成 C=1024/2048/4096 **+0.02~0.04s/组**；mini (N=8192) +0.34s/组
  → 50 组线上总增量 ≈ **0.3~1s**（÷4.8 汇率），远低于 +5s 门槛。
- state：s 本来就是 C 维向量，字节数不变（mini 实测 32.0MiB 前后一致）。
- 动态侧：计算图不变（x*s 与原先同路径），无增量。

## 5. 交付形态与守门设计（dev/smooth/solution.py）

- `SMOOTH_MODE = "ff_bal"`（默认开）；`"base"` = 位级回退开关。
- 拟合：`_bal_search`：A_c = calib[:-1] 各样本能量（≤160 行/组轮转抽样），
  B_c = 全权重列能量（in-sample，零迁移风险）；`s_c = exp(0.25·log(B/A))` 全局几何均值 1，
  |log s| ≤ 6。
- 守门：`_joint_proxy`（旋转感知双 mode、激活侧真量化、权重侧不量化）在 calib[-1]
  （≤160 行）上评估，`j_cand < 0.998·j_base` 才接受；拒绝 → 保留基线 s。
- 搜索用**局部 Generator**（不碰全局 RNG）→ 任何失败/拒绝路径与 v34 **位级相同**
  （已实测 torch.equal 验证：base 模式 == 原版；iid 拒绝 == 原版）。
- 官方 self_check：mini 22/22、stress c2048_wspike 19/19 通过（ff_bal 默认开）。

## 6. 与 §7 死路定理的关系（为什么这不是第五例）

四定理拟合的都是 C×C 级变换吃校准噪声；本机制不同：
1. 拟合对象是**持久通道统计量**（每通道能量，C 个参数、四次方根阻尼），
   mini 实测 test/calib 通道相关 0.64~0.94 —— 结构真实存在且跨样本持久；
2. 权重侧补偿完全 in-sample；
3. iid 正交检验（§7 规定的近正交检验等价物）：无结构数据守门 8/8 正确拒绝、位级回退；
4. 离群 token 数据（outl）守门 8/8 拒绝 —— 保守方向正确。

残余风险：判题某组 calib 内部有结构而 test 无（guard 看不见 test）→ mini 线性侧证据
（test 共享 calib 结构）+ 线性离线→线上迁移率 0.79 都反对此情形；且该风险被限制在
「该组收益归零」而非负值（接受的 s 是阻尼闭式解，非激进拟合）。
